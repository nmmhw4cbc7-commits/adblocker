Blocks ad requests before your browser makes them.

Lime Adblocker checks every outgoing request against a local ruleset of known ad and tracking domains, using Chrome's declarativeNetRequest API. Matches never leave the browser: nothing is fetched, and nothing is hidden after the fact.

    Extract the downloaded source code locally.

  2. Open extensions

    Go to chrome://extensions in the address bar.

  3. Enable developer mode

    Toggle the switch in the top-right corner of the page.

  4. Load the unpacked extension

    Click the corresponding button and select the unzipped folder.
