CHROME-EXTENSION · MANIFEST V3 · DECLARATIVENETREQUEST

Ads aren't hidden.
They're intercepted.

Lime Adblocker checks every request locally against a ruleset of known ad and tracking domains — before the connection is ever made. No script hides elements after the fact, no data leaves the browser.

PROCESS

What happens on every request

Three steps, all running inside the browser — no server, no cloud lookup.

01 · REQUEST

A resource is requested

Chrome wants to load a script, image, or iframe, triggered by the page you're on.

02 · MATCH

The ruleset checks the domain

declarativeNetRequest compares the target against the local blocklist — directly in Chrome, no outside lookup.

03 · DECISION

Drop or allow

On a match, the connection is never made in the first place. Everything else loads unchanged.

SETUP

Installation

Not yet listed on the Chrome Web Store — until then, install manually in four steps.

01
Unzip the archive

Extract the downloaded source code locally.

02
Open extensions

Go to chrome://extensions in the address bar.

03
Enable developer mode

Toggle the switch in the top-right corner of the page.

04
Load the unpacked extension

Click the corresponding button and select the unzipped folder.
