Simple AdBlocker

Eine leichte Chrome-Extension, die bekannte Werbe- und Tracking-Domains blockiert (Manifest V3, declarativeNetRequest).

Diese Seite ist eine reine Info-/Download-Seite — Chrome-Extensions laufen nicht direkt über GitHub Pages. Zum Nutzen musst du die Dateien herunterladen und manuell in Chrome laden, oder die Extension über den Chrome Web Store installieren.

Quellcode herunterladen (.zip)

Installation (manuell)

  1. ZIP entpacken
  2. chrome://extensions in Chrome öffnen
  3. Entwicklermodus aktivieren
  4. Entpackte Erweiterung laden klicken und den entpackten Ordner auswählen
